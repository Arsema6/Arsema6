## 💼 Core Project Deep-Dives

### 🎙️ [Applicant Path](https://github.com) — Multilingual AI-Assisted Application Processing
An asynchronous multi-modal AI agent prototype built independently in under 48 hours to automate complex administrative workflows.
*   **The Architecture:** Ingests highly unstructured audio voice notes and physical workshop/license documentation, leveraging **Groq Whisper-large-v3-turbo** and **Gemini Vision** to parse inputs into validated schemas.
*   **State Machine Engineering:** Designed a deterministic form state tree mapping approximately 65 distinct parameters. The agent cross-checks input streams for structural or logical contradictions and dynamically maps targeted follow-up question vectors to isolate missing fields without data hallucination.
*   **Localization Layer:** Tailored to fully support native localized workflows across English, Amharic, and Afaan Oromo audio profiles.
*   *Tech Stack:* Python, Streamlit, Gemini API, Groq APIs, Audio Segment Processing

### 🤖 [Customer Complaint Chatbot](https://github.com) — Semantic Customer Complaint Analytics
An intelligent semantic retrieval and answering system built to transform raw consumer narrative text into evidence-backed financial business insights.
*   **Production Scoping:** Engineered around a subset of 3,194 consumer complaints filtered systematically from a 6GB, 500K-row dataset representing financial domains (Credit Cards, Personal Loans, Savings, and Money Transfers).
*   **Optimization Layer:** Designed to resolve complex queries under constrained local hardware. Implemented text-chunking strategies and vectorized semantic indexing via **sentence-transformers (all-MiniLM-L6-v2)** and **ChromaDB/FAISS**. 
*   **Transparency:** Built an interactive Gradio/Streamlit dashboard displaying explicit source-evidence text chunks alongside LLM completions to eliminate black-box responses.
*   *Tech Stack:* Python, pandas, scikit-learn, LangChain, Hugging Face, FAISS, ChromaDB

### 📈 [Credit Risk Model](https://github.com) — Behavioral Disengagement Analytics
An end-to-end machine learning engineering pipeline built to score and characterize consumer behavioral patterns using alternative platform data.
*   **Feature Engineering:** Processed 95,662 customer transaction histories spanning an alternative eCommerce ecosystem (**Xente platform**), aggregating messy transactional records into customer-level RFM features.
*   **Rigorous Validation:** Developed a reproducible model validation strategy comparing interpretable classification layers with non-linear models (**XGBoost, Scikit-learn**), achieving an 85%+ classification accuracy.
*   **Data MLOps:** Integrated **Data Version Control (DVC)** to track data transformations, auditable pipelines, and dataset versioning, exposing model inference through a continuous integration (**CI/CD**) automated checking framework.
*   *Tech Stack:* Python, XGBoost, Scikit-learn, MLflow, FastAPI, DVC, Docker, GitHub Actions

A highly testable, scheduled data pipeline designed to parse, ingest, clean, and structure unstructured message data at scale.
*   **ETL Orchestration:** Developed an automated Python extraction engine using the **Telethon framework** to pull unstructured programmatic message blocks across localized medical and pharmaceutical channels.
